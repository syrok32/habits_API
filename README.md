
# Tracker Привычек

Habits Tracker - это API на базе Django REST Framework для управления личными привычками. Пользователи могут создавать, обновлять, удалять и просматривать привычки, с поддержкой публичных и приватных привычек, приятных привычек, наград и связанных привычек. Проект включает в себя валидацию при создании привычек и контроль доступа на основе владельца и публичности.

## Особенности
- **Управление привычками**: создание, чтение, обновление и удаление привычек.
- **Контроль доступа**: приватные привычки доступны только их владельцам; публичные привычки доступны всем.
- **Валидация**:
  - Время на выполнение привычки не должно превышать 120 секунд.
  - Периодичность должна быть от 1 до 7 дней.
  - Приятные привычки не могут иметь награды или связанные привычки.
  - Связанные привычки должны быть приятными привычками.
- **Пагинация**: список привычек имеет пагинацию с размером страницы по умолчанию 10.
- **Аутентификация**: используется система аутентификации Django с токенами или сессиями REST Framework.

## Требования
- Python 3.8+
- Django 4.x
- Django REST Framework 3.14.x
- База данных (например, SQLite для разработки, PostgreSQL для производства)

## Установка

1. **Клонировать репозиторий**:
   ```bash
   git clone https://github.com/yourusername/tracker_habits.git
   cd tracker_habits
   ```

2. **Создать и активировать виртуальное окружение**:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # На Windows: .venv\Scripts ctivate
   ```

3. **Установить зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Применить миграции**:
   ```bash
   python manage.py makemigrations
   python manage.py migrate
   ```

5. **Создать суперпользователя** (необязательно, для доступа к админке):
   ```bash
   python manage.py createsuperuser
   ```

## Запуск проекта

1. **Запустить сервер разработки**:
   ```bash
   python manage.py runserver
   ```

2. **Доступ к API**:
   - Корень API: `http://127.0.0.1:8000/`
   - Панель администратора: `http://127.0.0.1:8000/admin/`

## Тестирование

Проект включает юнит-тесты для API привычек, охватывающие создание, список, получение, обновление и удаление привычек.

1. **Запуск тестов**:
   ```bash
   python manage.py test habits.tests
   ```

2. **Покрытие тестами**:
   Для генерации отчета о покрытии тестами, установите `coverage`:
   ```bash
   pip install coverage
   coverage run manage.py test
   coverage report
   ```

## API Эндпоинты

- **Список привычек**: `GET /api/habits/`
  - Возвращает публичные привычки (неаутентифицированным пользователям) или публичные и принадлежащие пользователю привычки (аутентифицированным).
- **Создать привычку**: `POST /api/habits/`
  - Требует аутентификации.
  - Пример запроса:
    ```json
    {
        "place": "Парк",
        "time_at": "08:30:00",
        "action": "бегать",
        "pleasant_habit": "",
        "period": 2,
        "time_to_complete": "00:02:00",
        "is_public": true
    }
    ```
- **Получить привычку**: `GET /api/habits/<id>/`
  - Доступно владельцам или если привычка публичная.
- **Обновить привычку**: `PUT /api/habits/<id>/`
  - Требуется право собственности.
- **Удалить привычку**: `DELETE /api/habits/<id>/`
  - Требуется право собственности.

## Структура проекта

- `habits/`: Основная директория приложения.
  - `models.py`: Определяет модель `Habits`.
  - `views.py`: Содержит `HabitViewSet` для логики API.
  - `serializers.py`: Определяет `HabitSerializer` для сериализации данных.
  - `tests.py`: Юнит-тесты для API.
  - `validators.py`: Кастомные валидаторы для полей привычек.
  - `pagination.py`: Кастомные настройки пагинации.
  - `urls.py`: Роуты API.
- `users/`: Управление пользователями (предполагается, не предоставлено).
- `manage.py`: Скрипт управления Django.

1. **Добавление новых фич**:

     ```python
         },
     }
     ```
